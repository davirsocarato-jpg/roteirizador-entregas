# Roteirizador de Entregas

Aplicação web simples, responsiva e funcional para organizar rotas de entregas no dia a dia.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Cadastre as entregas com cliente, endereço e coordenadas.
3. Clique em "Organizar rota" para otimizar a sequência.
4. Os dados ficam salvos no navegador usando `localStorage`.

## Acesso no celular

Para testar no celular, você pode:

- abrir a página em um navegador do celular na mesma rede Wi‑Fi;
- usar um serviço como GitHub Pages, Netlify ou Vercel;
- ou usar um túnel local como `ngrok` ou `localtunnel`.

## Estrutura

- `index.html` — estrutura da aplicação
- `styles.css` — layout visual
- `app.js` — lógica da rota e armazenamento local

## Exemplo de publicação no GitHub Pages

1. Faça push deste repositório para GitHub.
2. No GitHub, vá em Settings → Pages.
3. Selecione a branch `main` e a pasta raiz.
4. O site ficará disponível em algo como:
   `https://<seu-usuario>.github.io/roteirizador-entregas/`

## Observação

Este é um MVP funcional para uso prático em desktop e celular, sem necessidade de backend.
